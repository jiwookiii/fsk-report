보안 문서 계정 발급 도구 원본 HTML을 암호화하고 로그인 계정을 발급함 · 암호화는 이 브라우저 안에서만 처리로그인 화면 열기

1원본 HTML 선택

보안을 걸 보고서 HTML 원본(암호화 전 파일). 원본은 저장소에 올리지 말 것

2계정 만들기

로그인 후 화면 전체에 "회사 / 부서 / 사번 / 성명" 워터마크가 45° 대각선으로 고정 표시됨(계정별). 아이디는 대소문자 구분 없음. 비밀번호는 12자 이상 필수(공개 게시 파일은 누구나 내려받아 대입 시도가 가능함). [자동]은 14자 무작위 생성

받는 사람 (메모)아이디비밀번호부서 (워터마크)사번성명

매월 보고서만 교체할 때는 지난번에 내려받은 계정목록.csv를 불러오면 같은 아이디·비밀번호로 다시 발급됨

엑셀에서 여러 명 한 번에 붙여넣기

엑셀에서 받는 사람 · 아이디 · 부서 · 사번 · 성명 5열(머리글 없이)을 복사해 붙여넣기. 비밀번호 열을 넣으려면 6번째 열로 추가. 비밀번호가 없으면 자동 생성

3암호화 데이터 만들기

버튼을 누르면 report.enc.json이 내려받아짐. 이 파일이 로그인 화면(index.html)이 읽는 암호화 데이터임

배포용 계정 목록 — 접속 주소와 비밀번호는 다른 경로로 전달 (예: 주소는 메일, 비밀번호는 메신저). 계정목록 CSV는 저장소에 올리지 말 것

4게시

방법 A: 내려받은 report.enc.json을 저장소의 data/ 폴더에 올림(기존 파일 덮어쓰기). 방법 B: 아래에서 GitHub에 바로 게시

GitHub에 바로 게시 (방법 B)
3단계 생성 후 활성화됨
운영 시 주의
· 보고서 내용은 비밀번호로 암호화됨. 저장소가 공개여도 비밀번호 없이는 내용이 보이지 않음. 단, 암호문은 누구나 내려받을 수 있으므로 짧거나 추측 가능한 비밀번호는 금지
· 한 번 게시한 암호문은 저장소 이력에 남음. 계정을 회수해도 이전 게시분은 그 계정으로 계속 열림. 새 보고서부터 새 계정이 적용됨
· 원본 HTML과 계정목록 CSV는 저장소에 올리지 말 것. 한 번 올리면 이력에서 지우기 어려움
· 비밀번호를 잊으면 복구 불가. 원본 HTML과 계정목록 CSV는 따로 보관
· 로그인 기록(누가 언제 열었는지)은 남지 않음 · Chrome·Edge 최신 버전에서 사용
